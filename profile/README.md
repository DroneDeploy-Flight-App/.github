## Overview
DroneDeploy for Windows pairs the DroneDeploy flight app used in the field with a desktop workspace back at the office, where imagery already processed into a map or model in the cloud gets reviewed, measured, and shared. It's built for people who fly the same ground repeatedly, whether that's a construction site under active development, a farm field through a growing season, or a survey area being monitored over time, rather than for a single one-off aerial photo.

## Features
- [ ] Plan and run automated survey flights over a defined boundary
- [ ] Turn raw aerial photos into a single stitched map through cloud processing
- [ ] Generate 3D models and elevation surfaces alongside the map
- [ ] Measure distance, area, and volume directly on the finished map
- [ ] Share finished maps and reports with teammates who don't fly

> **Tip:** Fly the same boundary for each visit to a site so consecutive maps line up cleanly for side-by-side comparison.

## System Requirements
- Windows 10, 64-bit, or later
- A modern 64-bit processor
- The minimum RAM Windows itself requires, with headroom for map viewing
- Enough free storage for the app and any locally cached maps

## Installation
Installing DroneDeploy doesn't take long: the button above downloads the Windows installer, running it walks through a standard setup, and the first launch ends at a sign-in screen — an existing DroneDeploy account signs straight in, and a new one takes a moment to create.

## Getting Started
1. Start a new project in DroneDeploy and mark the boundary of the site you're capturing.
2. Fly the automated flight plan with a connected drone, or bring in imagery you already captured elsewhere.
3. Wait for cloud processing to finish, then open the finished map or model in the desktop app.
4. Add measurements, notes, or share the result with anyone on the team who needs it.

## FAQ
**Is DroneDeploy completely free?**
There's no permanent free version of DroneDeploy; it's commercial, subscription-based software, though a free trial is available for evaluating the platform first.

**Where do I get the DroneDeploy download?**
Use the download button at the top of this page, which links to the official Windows installer.

**Is owning a drone required?**
No — a drone helps for capturing new imagery, but it isn't required if you're working with imagery that's already been captured.
